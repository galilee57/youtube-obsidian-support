Français

youtube-to-obsidian crée des notes Markdown à partir de sous-titres YouTube ou d’une transcription collée. Elle fonctionne sur iPhone et iPad à partir d’iOS/iPadOS 17.

  1. Dans Réglages, choisissez OpenAI, Anthropic ou une API compatible OpenAI, puis renseignez l’URL HTTPS, le modèle et votre clé API personnelle. Enregistrez la configuration.
  2. Choisissez le dossier de destination dans Fichiers, par exemple iCloud Drive → Obsidian → votre Vault.
  3. Ajoutez un lien YouTube. Récupérez les sous-titres disponibles ou collez une transcription.
  4. Autorisez l’envoi au fournisseur affiché, générez la note, vérifiez-la et enregistrez-la.

Sous-titres indisponibles : certaines vidéos n’ont pas de sous-titres accessibles, ou YouTube peut refuser la requête. Collez une transcription que vous êtes autorisé à utiliser.

Erreur de génération : vérifiez le fournisseur, l’URL, le nom exact du modèle, la clé API, le quota et la connexion. Les appels API peuvent être facturés par le fournisseur ; un abonnement ChatGPT ou Claude ne fournit pas automatiquement une facturation API.

Dossier inaccessible : sélectionnez de nouveau le dossier dans Fichiers. Le choix du Vault est propre à chaque appareil.

Historique / iCloud : vérifiez la connexion au compte Apple, l’accès réseau et l’espace iCloud. La synchronisation est gérée par iOS. Les fichiers Markdown exportés et l’historique de l’app sont distincts.

RESET : efface les champs courants, pas les fichiers déjà enregistrés ni l’historique. Les nouvelles notes suivent la langue FR/EN sélectionnée ; une note existante n’est pas traduite automatiquement.

Pour demander de l’aide, indiquez la version de l’app, la version iOS et le message d’erreur, sans envoyer de clé API ni de document confidentiel.

English

Choose your AI provider, HTTPS URL, model, and personal API key in Settings, then save the configuration. Select a destination in Files, add a YouTube link, fetch available captions or paste a transcript, consent to sending it to the displayed provider, and generate your note. Review it before saving.

If captions are unavailable, paste a transcript you are entitled to use. For generation errors, check the endpoint, model, API key, quota, and network. Provider API charges are separate. Choose the vault folder again if access has been lost. iCloud syncing is handled by iOS.

RESET clears the current fields, not saved files or history. New notes follow the selected English/French language. Existing notes are not translated automatically.

When requesting help, include the app and iOS versions and the error message. Never send an API key or confidential transcript.
